# Foundry Loadout — дизайн-система

Статус: принята для vertical slice 2026-08-19. Рабочее имя остаётся codename до решения брендового вопроса.

## Направление

Практичный тёмный справочник для ведущего, который настраивает Foundry VTT перед игрой. Интерфейс должен напоминать хорошо собранную техническую памятку: плотный, спокойный, без магазинной витрины, игровых иллюстраций и тяжёлой анимации.

Приоритеты в порядке применения:

1. Выбрать правильную major-версию Foundry VTT.
2. Быстро понять назначение и статус модуля.
3. Увидеть зависимости и точный manifest URL.
4. Скопировать ровно одну ссылку без двусмысленности.

Не используются: hero-иллюстрации, карусели, glassmorphism, неон, декоративное свечение, счётчики популярности, рейтинги, bulk actions, панель сборки и диалог экспорта.

## Типографика

- Основной стек: `Inter, "Segoe UI Variable", "Segoe UI", system-ui, sans-serif`.
- URL, package ID и версии: `ui-monospace, "Cascadia Code", "SFMono-Regular", Consolas, monospace`.
- Внешние web-font запросы не обязательны: системный стек быстрее и надёжно показывает кириллицу.
- Базовый размер: 16 px; line-height основного текста 1.55.
- Scale: 13 / 14 / 16 / 18 / 24 / clamp(32–52) px.
- Один `h1`; заголовки карточек — `h2`, секций — `h2`; визуальный размер не нарушает семантику.
- Длина поясняющего текста — до 70 символов в строке.

## Геометрия и ритм

- Шкала отступов: 4, 8, 12, 16, 24, 32, 48, 64 px.
- Максимальная ширина контента: 1280 px.
- Горизонтальные поля: 16 px до 767, 24 px от 768, 32 px от 1024.
- Радиусы: 8 px controls, 12 px карточки, 999 px только для компактных badges.
- Тени почти не используются; иерархию создают фон и границы.
- Интерактивная цель — не меньше 44×44 CSS px, промежуток между соседними controls — от 8 px.

## Каркас страницы

1. Skip link «К каталогу».
2. Компактный header: codename, подпись «Каталог manifest-ссылок», неофициальный статус.
3. Intro: одно предложение о назначении без рекламного слогана.
4. Панель управления: переключатель V13/V14; в полном MVP — поиск и filters.
5. Строка результата с выбранной версией и количеством карточек.
6. Сетка карточек.
7. Короткая инструкция ручной установки.
8. Footer с повторным юридическим пояснением и ссылкой на источники.

Первый viewport должен сразу показывать переключатель версии и начало первой карточки. Header не фиксируется: он не должен заслонять focus и уменьшать рабочую область на телефоне.

## Переключатель версии

- Нативные radio внутри `fieldset` с видимым `legend` «Версия Foundry VTT».
- Визуально — segmented control из двух равных кнопок `V13` и `V14`.
- Выбранное состояние: accent-фон, тёмный текст, `aria-checked` через нативный radio.
- Переключение клавишами работает по браузерному контракту radio group.
- Смена версии заменяет track каждой карточки; одновременно две ветки не показываются.

## Поиск и фильтры полного MVP

- Поиск имеет постоянный label, а не один placeholder.
- Select/checkbox используются вместо самодельных dropdown.
- Filter controls переносятся на новую строку; горизонтальная прокрутка не допускается.
- Результат обновляется без live-спама: одна строка `role="status"` сообщает осмысленное количество.
- Empty state объясняет причину и предлагает «Сбросить фильтры».

## Карточка модуля

Порядок внутри карточки:

1. Название и package ID.
2. Статус проверки, license и system badges.
3. Человеческое описание в 1–3 предложениях.
4. Версия модуля и компактная моноширинная строка raw compatibility `minimum · verified · maximum`; отсутствующие поля показываются как «не указано», не вычисляются.
5. Дата проверки.
6. Обязательные и рекомендуемые зависимости отдельными строками.
7. Manifest URL целиком показан внутри кнопки: нажатие по области ссылки сразу копирует её.
8. Вторичная ссылка «Официальный проект».

Карточка сама не кликабельна. Hover не двигает её и не создаёт ложного affordance.

## Badges и предупреждения

- Badge — статический `span`, не button.
- Текст не обрезается и по возможности остаётся на одной строке; коллекция badges переносится целиком.
- `Проверено`: зелёный текст/бордер и полный label.
- `Заявлено автором`: синий.
- `Требует проверки`: жёлтый.
- `Ссылка недоступна`: розово-красный.
- Premium: нейтральный badge и отдельный текст о персональной установке; кнопки копирования нет.
- Предупреждение содержит причину и следующий шаг, а не одно слово «Ошибка».

## Кнопки и Clipboard feedback

- Область manifest URL — нативная кнопка высотой от 44 px; весь URL остаётся видимым, а hover/focus явно показывают интерактивность.
- Иконка не нужна: видимый текст точнее и не требует дополнительной зависимости.
- Hover/pressed меняют цвет/opacity, не размер и положение.
- Focus ring: 3 px `--focus` с offset 3 px.
- Toast располагается в потоке/нижней области, `role="status"`, `aria-live="polite"`, не крадёт focus.
- Успех: «Manifest-ссылка скопирована».
- Ошибка: поле URL получает focus и выделение, сообщение — «Выделите ссылку и скопируйте её вручную».

## Адаптивность

- 375 px: одна колонка, controls и кнопки на всю доступную ширину, URL переносится.
- 768 px: controls в две строки, карточки остаются одной колонкой для читаемости.
- 1024 px: сетка из двух колонок.
- 1440 px: две или три колонки только если карточка сохраняет удобную ширину не меньше 360 px.
- При zoom 200% layout работает как узкий viewport; fixed-height containers запрещены.
- Landscape mobile сохраняет основной вертикальный scroll без вложенных scroll-region.

## Motion

- Длительности: 120 ms pressed, 180 ms hover/focus, 220 ms смена состояния.
- Анимируются только opacity, color, border-color и transform для самого toast не более 8 px.
- `prefers-reduced-motion: reduce` отключает transform и сокращает transition до 0.01 ms.
- Контент никогда не скрывается до запуска анимации; GSAP не добавляется.

## Тексты

- Тон: опытный ведущий объясняет другому ведущему, что именно делает модуль и где риск.
- Без «лучшего опыта», «мощных решений», «революции», восклицаний и рекламных CTA.
- `Foundry VTT`, а не сокращение `Foundry`, когда речь о продукте.
- `Manifest-ссылка`, `скопировать`, `установить вручную`; не «скачать модуль».

## Контроль перед UI-сдачей

- Контраст normal text ≥4.5:1, meaningful borders/focus ≥3:1.
- Полный сценарий доступен Tab, Shift+Tab, стрелками radio group, Enter и Space.
- Focus не закрывается toast или другими overlay.
- Нет emoji как структурных иконок и нет самодельного SVG-арта.
- Нет горизонтального scroll на 375 px и при 200% zoom.
- Проверены widths 375, 768, 1024 и 1440 px и `prefers-reduced-motion`.
- Длинные URL используют `overflow-wrap:anywhere`, flex/grid children — `min-width:0`.
- Неофициальный статус виден на первом экране и в footer.
